# Paint by Numbers

A portfolio project that converts an uploaded image into a printable
paint-by-numbers design.

## Project layout

- `frontend/` — React and TypeScript user interface built with Vite.
- `backend/` — FastAPI service and image-processing code.

## Planned MVP

1. Upload an image.
2. Choose the number of colors.
3. Generate a simplified preview.
4. Display numbered regions and a color key.
5. Download the result.
